⌨️ 命令行参考
在容器内执行（docker exec -it catdock bash），以下为全部命令行工具：
adminctl — 管理员账户管理
列出全部用户 adminctl list
添加管理员 adminctl add <用户名>
删除管理员（至少保留一个） adminctl del <用户名>
修改管理员密码 adminctl password <用户名>
userctl — 下载用户管理
添加用户 userctl add <用户名>
删除用户（含全部数据） userctl del <用户名>
修改用户密码 userctl password <用户名>
禁用用户 userctl ban <用户名>
解禁用户 userctl unban <用户名>
banip — IP 封禁管理
查看封禁列表 banip show
封禁 IP banip add <IP>
解封 IP banip del <IP>
debug — 调试模式开关
查看当前状态（yes/no 可简写为 y/n） debug show
开启调试模式（输出详细过程日志） debug yes
关闭调试模式（仅输出关键下载结果） debug no
